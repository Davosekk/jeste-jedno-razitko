# Aktuální plán — Python + Pygame

Poslední změna zadání: 17. 11. 2026. Uživatel chce běžné, snadno čitelné Python soubory ve VS Code, bez Godotu nebo podobného herního editoru. Dřívější webová i Godot verze jsou odložené. Zachováváme z nich jen nápad a malý rozsah.

Vylosováno: **Interaktivní fikce / adventura**, téma **Úřad a byrokracie**. Hra bude 2D příběhová adventura shora: chůze, předměty, řešení úkolů a krátké dialogy s rozhodnutími. Přesný školní výklad společné žánrové kategorie z fotky neznáme.

## Pevný rozsah

Jedno malé patro úřadu, nejvýše 3 zóny, 2 úředníci, 3 předměty/dokumenty, jeden úkol získat povolení a dva konce. Přibližně 5 minut hraní. Bez účtů, multiplayeru, soubojů, ukládání a rozsáhlých dialogových stromů.
